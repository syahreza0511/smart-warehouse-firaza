# Scope MVP

Fitur utama:

## Authentication

-   Login.
-   Logout.
-   JWT Authentication.
-   Role Based Access Control.

Role:

Owner: - Dashboard monitoring. - Melihat inventory. - Melihat report.

Staff Warehouse/Admin: - Mengelola material. - Stock In. - Stock Out. -
Stock Opname.

## Inventory Management

Scope:

Raw Material Inventory.

Tidak menggunakan data asli UMKM.

Menggunakan synthetic dataset realistis.

Contoh:

-   Kardus.
-   Ribbon.
-   Bubble wrap.
-   Packaging material.
-   Supporting material.
