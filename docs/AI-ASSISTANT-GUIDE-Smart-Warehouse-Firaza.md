# AI Assistant Guide

# Smart Warehouse Firaza

## 1. Tujuan

Dokumen ini menjelaskan bagaimana menggunakan AI assistant secara
efektif selama pengerjaan capstone.

------------------------------------------------------------------------

# 2. Peran AI

AI berperan sebagai:

Senior Developer Assistant.

AI membantu:

-   memahami requirement.
-   membuat draft kode.
-   debugging.
-   review.

Developer tetap menentukan keputusan.

------------------------------------------------------------------------

# 3. Context yang diberikan ke AI

Jangan selalu memberikan semua file.

Gunakan sesuai kebutuhan.

------------------------------------------------------------------------

Contoh Backend:

Berikan:

-   PROJECT-CONTEXT
-   DATABASE-DESIGN
-   API-DOCUMENTATION
-   FEATURE-SPECIFICATION

------------------------------------------------------------------------

Contoh Frontend:

Berikan:

-   USER-FLOW
-   API-DOCUMENTATION
-   CODING-GUIDELINE

------------------------------------------------------------------------

# 4. Prompt Workflow

Gunakan:

## Tahap 1

Minta analisis.

Contoh:

"Jelaskan rencana implementasi fitur ini sebelum coding."

------------------------------------------------------------------------

## Tahap 2

Review rencana.

------------------------------------------------------------------------

## Tahap 3

Minta implementasi.

------------------------------------------------------------------------

# 5. Jangan memberikan prompt terlalu luas

Buruk:

"Buatkan aplikasi inventory."

Baik:

"Implementasikan TASK-008 Material API sesuai dokumentasi."

------------------------------------------------------------------------

# 6. Saat Debugging

Berikan:

-   Error message.
-   File terkait.
-   Expected behavior.
-   Actual behavior.

------------------------------------------------------------------------

# 7. Menghemat Token

Gunakan:

Context tepat.

Bukan:

Semua file setiap saat.

------------------------------------------------------------------------

# 8. Workflow Claude

Rekomendasi:

1.  Simpan repository di GitHub.
2.  Hubungkan dengan coding environment.
3.  Berikan dokumentasi project.
4.  Kerjakan task satu per satu.

------------------------------------------------------------------------

# 9. Prinsip Utama

AI mempercepat pekerjaan.

AI bukan pengganti pemahaman developer.
